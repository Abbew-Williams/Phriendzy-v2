Add public media

This gallery is public. Anyone with the link can view and download files added here.

  1. Open the repository's media folder in GitHub.
  2. Upload the photos or videos you want everyone to see.
  3. Add each file to media/media.json using the documented format in the README.
  4. Commit your changes and wait for GitHub Pages to publish them.
Open media folder on GitHub

Only repository contributors can add or remove gallery files. There is no sign-in or in-page upload on GitHub Pages.
